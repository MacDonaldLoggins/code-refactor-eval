# CHANGE_ME: Refactor Task

## Goal

CHANGE_ME：说明当前变化压力、需要改善的责任边界，以及为什么现在需要重构。

## Functional and compatibility requirements

- CHANGE_ME：列出必须保持的用户可见行为、公共 API、错误行为和副作用。
- CHANGE_ME：列出本次明确允许的行为变化；纯重构任务通常应为空。

## Scope

- Allowed production areas: `CHANGE_ME`
- Protected tests/evaluation files must not be modified.

## Completion

- 行为契约得到可执行证据支持。
- 目标责任或变化成本确实改善，而不只是移动代码或降低某个静态指标。
