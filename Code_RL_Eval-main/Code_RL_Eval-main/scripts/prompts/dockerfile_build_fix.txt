## 绝对不可违反的约束

1. **禁止删除或改动 Claude Code CLI 安装相关的任何指令。** 以下这些行必须**原样保留**：
   - `COPY install_claude_code.sh /tmp/install_claude_code.sh`
   - `RUN SKIP_APT_INSTALL=1 CLAUDE_INSTALL_METHOD=npm bash /tmp/install_claude_code.sh ...`
   - `COPY settings.json /root/.claude/settings.json`
   - 安装 Node.js + npm 的那条 `apt-get install ... nodejs npm` 指令
   - `ENV PATH="/root/.local/bin:${PATH}"`
2. **禁止删除或改动 OpenAI Codex CLI 安装相关的任何指令。** 以下这些行必须**原样保留**：
   - `COPY install_codex.sh /tmp/install_codex.sh`
   - `RUN SKIP_APT_INSTALL=1 bash /tmp/install_codex.sh ...`
   - `RUN mkdir -p /root/.codex`
   - `COPY codex_config.toml /root/.codex/config.toml`
3. **禁止删除国内镜像源配置**（清华 apt/pip 源、代理清空 `ENV HTTP_PROXY=""...`、`pip config set global.index-url`）。
4. **禁止删除评测脚本的 COPY**（`verifier.py hard_gates.py objective_metrics.py rubric.py setup.py prompt.md`）。
5. 不要引入需要联网访问被墙资源的步骤；所有包源继续走国内镜像。
6. 不要改动 `FROM` 基础镜像的大版本，除非错误明确由基础镜像导致。

## 修复思路提示

- 仔细阅读构建错误日志，定位失败的那一条指令。
- **build 阶段不需要安装 `requirements.txt`**：项目依赖（含 `-e ./ext`、`-e .[extra]` 这类 editable 安装、以及第三方包清单）在镜像构建时**不需要、也不应该**安装。这类失败的正确修法是**移除或跳过安装 `requirements.txt` / editable 依赖的那条 `RUN pip install ... -r requirements.txt`（及 `-e .` 等）指令**，而不是想办法让它装成功。源码通过 COPY repo/ + PYTHONPATH 使用，依赖问题留给运行时解决。
- 因此当错误来自 `-r requirements.txt`、`-e ./xxx`、`pip install .[extra]` 时：直接删掉那条安装指令即可（COPY requirements.txt/setup.py 等清单文件的行可保留或一并去掉，只要不再执行安装）。
- 其余情况（缺少系统依赖、apt 包名错误等）按日志正常修复。
- **但升级 pip、安装评测必需的 `pytest`、`ruff` 这类工具的 `pip install` 指令必须保留**，只跳过项目自身依赖清单的安装。
