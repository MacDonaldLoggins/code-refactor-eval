### 固定 Rubric 规则

Rubric 维度来自固定的 C1-C12 维度库。任务只能实例化维度上下文，不能新增、删除或改权重。

硬门控由 `hard_gates.py` 负责，客观指标由 `objective_metrics.py` 负责；Rubric 不重复评测试通过、行为保持硬判定、复杂度、lint、覆盖率或类型检查。

### 任务级实例化字段

需要输出：
1. `scenario`：优先使用 `scenario_index.json` 中的标准 ID，例如 `extract_function`。
2. `behavior_to_preserve`：列出返回值、异常、顺序、副作用、API 等具体行为。
3. `known_bad_patterns`：说明要消除的旧结构或坏味道。
4. `expected_new_structure`：说明重构后必须出现的结构证据。
5. `evidence_hints`：说明人工/LLM Rubric 评审需要查看的文件、符号或 diff 位置。

请现在只输出一个 JSON 对象，字段与"任务级实例化字段"一一对应；不要生成 Python 代码，不要输出 Markdown 以外的额外文本。
